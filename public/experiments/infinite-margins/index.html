Making room for a thought

A page gives a thought somewhere to rest. We follow a line, then another, until a sentence asks us to pause. The pause is part of the reading.

At the edge of the page, there is room for a question. A word to return to. A small connection that is not quite ready to become an answer.

Good tools make that movement feel ordinary. We can step away, put something beside the text, and return without having to find our place again.

The page is still here. The margins belong to the same read.

Margins open · chapter one

Use the buttons, or focus the canvas: +/− zoom, 0 fits, M opens the margins, arrow keys pan. Control or Command + wheel zooms; plain wheel pans the margins. The first inward crossing over the page catches at 100%. Pause for 300ms, then start a fresh zoom to go deeper. Outward zoom continues without a gesture hold.
